TopWar Auto Translate

Privacy Policy / 개인정보처리방침

Effective date / 시행일: September 22, 2026

TopWar Auto Translate is an unofficial Chrome extension that automates the built-in chat translation feature available in the TopWar H5 web game.

1. Data processed by the extension

The extension accesses text from chat messages that are currently visible on `https://h5.topwargame.com/h5game/*`.

This text is used only to:

  • determine whether a message contains translatable text;
  • detect the message language locally in the browser;
  • determine whether the message matches the user's selected translation-exclusion language; and
  • invoke TopWar's built-in translation action when appropriate.

    • The extension may therefore process website content, user-generated content, and personal communications that appear in the game's chat interface.

    2. Local language detection

    Language detection is performed locally in the user's browser.

    The extension does not send chat text to a developer-operated server for language detection.

    3. TopWar translation service

    When the extension invokes TopWar's built-in translation action, TopWar itself may transmit the selected chat message to TopWar's own translation service. This is the same game functionality that is used when a user manually presses TopWar's translation button.

    The developer of this extension does not control TopWar's data handling. TopWar's own terms and privacy practices apply to data processed by TopWar services.

    4. Data sent to the extension developer

    The extension does not send the following to the extension developer:

  • chat messages;
  • browsing history;
  • account credentials;
  • authentication tokens;
  • personal identifiers;
  • analytics or telemetry;
  • advertising identifiers; or
  • usage tracking data.

    • No developer-operated backend server is used by the extension.

    5. Local settings

    The selected translation-exclusion language is stored locally in the browser using the TopWar page's local storage.

    This preference is used only to preserve the user's setting between sessions.

    6. Advertising and sale of data

    The extension contains no advertising.

    The extension developer does not sell, rent, or use user data for advertising, profiling, or personalized marketing.

    7. Data retention

    The extension developer does not receive or retain chat content or other user data.

    The local translation-exclusion setting remains in the browser until the user changes it, clears site data, removes the extension, or otherwise removes the relevant browser storage.

    8. Limited Use

    Any user data accessed by the extension is used only to provide the extension's single purpose: automatically invoking TopWar's built-in chat translation when appropriate.

    The extension does not use accessed data for unrelated purposes.

    9. Security

    The extension does not operate a remote server and does not transmit user data to the extension developer.

    Any network transmission performed by TopWar's built-in translation functionality is controlled by TopWar.

    10. Third-party relationship

    TopWar Auto Translate is an unofficial extension and is not affiliated with, endorsed by, or sponsored by TopWar or its publisher.

    11. Changes to this policy

    If the extension's data practices change, this privacy policy will be updated before those changes are released to users where required.

    12. Contact

    For privacy questions, please use the publisher contact information displayed on the Chrome Web Store listing.

    TopWar Auto Translate는 TopWar H5 웹게임에 존재하는 채팅 번역 기능을 자동으로 실행하는 비공식 Chrome 확장 프로그램입니다.

    1. 확장 프로그램이 처리하는 데이터

    확장 프로그램은 `https://h5.topwargame.com/h5game/*`에서 현재 화면에 보이는 채팅 메시지 텍스트에 접근합니다.

    이 텍스트는 다음 목적에만 사용됩니다.

  • 번역할 수 있는 텍스트인지 확인
  • 브라우저 내부에서 메시지 언어 감지
  • 사용자가 선택한 번역 제외 언어와 일치하는지 판단
  • 필요한 경우 TopWar의 기존 번역 기능 실행

    • 따라서 게임 채팅에 표시되는 웹사이트 콘텐츠, 사용자 생성 콘텐츠 및 개인 간 커뮤니케이션 내용을 처리할 수 있습니다.

    2. 로컬 언어 감지

    언어 감지는 사용자의 브라우저 내부에서 수행됩니다.

    언어 감지를 위해 채팅 텍스트를 개발자 운영 서버로 전송하지 않습니다.

    3. TopWar 번역 서비스

    확장 프로그램이 TopWar의 기존 번역 기능을 실행하면 TopWar 자체 기능에 의해 해당 채팅 메시지가 TopWar의 번역 서비스로 전송될 수 있습니다.

    이는 사용자가 게임에서 번역 버튼을 직접 눌렀을 때 사용되는 것과 동일한 게임 기능입니다.

    확장 프로그램 개발자는 TopWar의 데이터 처리 방식을 제어하지 않으며, TopWar 서비스에서 처리되는 데이터에는 TopWar의 약관 및 개인정보 처리 기준이 적용됩니다.

    4. 개발자에게 전송되는 데이터

    확장 프로그램은 다음 정보를 확장 프로그램 개발자에게 전송하지 않습니다.

  • 채팅 메시지
  • 브라우징 기록
  • 계정 자격 증명
  • 인증 토큰
  • 개인 식별 정보
  • 분석 또는 텔레메트리 데이터
  • 광고 식별자
  • 사용 추적 데이터

    • 확장 프로그램은 개발자 운영 백엔드 서버를 사용하지 않습니다.

    5. 로컬 설정

    사용자가 선택한 번역 제외 언어는 브라우저의 TopWar 페이지 로컬 스토리지에 저장됩니다.

    이 설정은 다음 접속에서도 사용자의 선택을 유지하기 위한 목적으로만 사용됩니다.

    6. 광고 및 데이터 판매

    확장 프로그램에는 광고가 없습니다.

    개발자는 사용자 데이터를 판매, 대여하거나 광고, 프로파일링 또는 맞춤형 마케팅에 사용하지 않습니다.

    7. 데이터 보관

    확장 프로그램 개발자는 채팅 내용 또는 기타 사용자 데이터를 수신하거나 보관하지 않습니다.

    로컬에 저장된 번역 제외 언어 설정은 사용자가 설정을 변경하거나, 사이트 데이터를 삭제하거나, 확장 프로그램을 제거하거나, 관련 브라우저 저장소를 삭제할 때까지 유지될 수 있습니다.

    8. 제한적 사용

    확장 프로그램이 접근하는 사용자 데이터는 오직 하나의 목적, 즉 필요한 경우 TopWar의 기존 채팅 번역 기능을 자동 실행하기 위해서만 사용됩니다.

    관련 없는 다른 목적으로 사용하지 않습니다.

    9. 보안

    확장 프로그램은 원격 개발자 서버를 운영하지 않으며 사용자 데이터를 개발자에게 전송하지 않습니다.

    TopWar 내장 번역 기능에 의해 발생하는 네트워크 통신은 TopWar가 관리합니다.

    10. 제3자와의 관계

    TopWar Auto Translate는 비공식 확장 프로그램이며 TopWar 또는 해당 퍼블리셔와 제휴, 보증 또는 후원 관계가 없습니다.

    11. 정책 변경

    확장 프로그램의 데이터 처리 방식이 변경되는 경우 필요한 경우 사용자에게 해당 변경이 적용되기 전에 개인정보처리방침을 업데이트합니다.

    12. 문의

    개인정보 관련 문의는 Chrome Web Store 등록 페이지에 표시된 게시자 연락처를 이용해 주십시오.
