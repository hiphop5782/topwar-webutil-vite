# 2026-09-21 AdSense 재거절 1차 분석

## 결론과 범위

거절 사유는 미확인이다. 첨부 메일은 한국 시각 2026-09-21 06:58 발송된 일반적인 신청 수정 안내이며, 콘텐츠 부족·낮은 품질 문구는 일반 팁이다. 사용자는 관리 화면에도 상세 사유가 나오지 않는다고 답했다. 특정 정책 위반으로 확정하지 않는다.

현재 저장소와 운영 사이트의 직접 HTTP 응답을 확인했다. Google 심사 당시 응답, 실제 심사 로그, Search Console, 로그인한 AdSense 계정, 모바일 시각 검증은 이번 분석에 포함되지 않는다. 최신 운영 응답에는 거절 이후 변경이 포함될 수 있다.

## 확인한 정상 항목

- `/`, `/ko/`, `/robots.txt`, `/ads.txt`, `/sitemap.xml`: HTTP 200.
- robots.txt: 일반 크롤러 접근 허용. 특정 Google 봇이나 지역별 방화벽 통과까지 보장하는 결과는 아니다.
- ads.txt: 첨부 메일의 게시자 ID와 일치하는 DIRECT 레코드 존재.
- 루트와 한국어 홈 canonical: `https://www.progamer.info/ko/`로 일치.
- sitemap: loc 60개. 이전 개선 보고서의 콘텐츠 중심 정리가 운영에 반영됨.
- `/ko/information/data/server/?server=3223`: HTTP 200, noindex, follow.
- 임의 없는 URL: HTTP 404, noindex, follow.
- 분석 글 중심 홈, 주제별 자료실, 운영자 소개 확인.
- 체력 계산기 운영 HTML에 원리·주의사항·FAQ 확인.
- 전투 공식 통합 글에는 실험 조건과 정수 피해량, 계산 및 한계 설명 존재. 사이트 전체가 독창적 콘텐츠 부재라는 결론은 근거 부족.

## 우선 개선 후보

### 1. 홈의 불완전한 초기 통계 — 확실한 구현 문제

현재 운영 홈 HTML에서 추적 플레이어·활동 인원·전투력 수치가 `-`, 서버 활동 분포가 모두 0으로 출력된다. 데이터 기준일은 9월 21일로 나타난다. `src/components/screen/Home.jsx`는 프리렌더 빌드일 때 전체 서버 집계를 건너뛰고 playerCountState를 error로 설정한다. 데이터가 없는 상태에서 표시되는 0이 실제 관측값처럼 보일 수 있다.

브라우저 실행 후 보충될 가능성과 최초 HTML의 불완전성은 구분해야 한다. Google이 반드시 초기 HTML만 본다는 뜻은 아니다. 개선은 빌드에서 완성된 집계 스냅샷을 사용하거나, 집계가 없을 때 해당 카드 대신 명확한 미집계 안내를 제공하는 방향이 적절하다.

### 2. 이미지 중심 대표 글 — 콘텐츠 전달 개선 후보

공개 Markdown 16개에서 front matter와 이미지 문법을 제외한 본문을 조사했다. 아래 수치는 품질 판정이나 승인 기준이 아니라 텍스트 전달 방식의 측정이다.

| 글 | 이미지 수 | 이미지 외 본문 문자 수 |
|---|---:|---:|
| 월드보스 공격 설정 | 7 | 0 |
| 칩 전문화 | 4 | 0 |
| 타이탄 재련 | 8 | 0 |
| 서버전(SvS) | 25 | 55 |

월드보스·칩 전문화 운영 HTML도 제목·작성 정보·관련 링크 외 설명 텍스트가 없다. 특히 타이탄 재련은 홈의 성장·장비 대표 링크다. 이미지 자체의 독창성·정확성·권리 관계는 이번 분석에서 판정하지 않았다. Google 정책상 이미지도 게시자 콘텐츠이므로 이미지 중심이라는 이유만으로 저가치 또는 위반으로 확정할 수 없다.

보강 방향: 이미지의 실제 설명을 읽고 핵심 설정, 선택 이유, 적용 조건, 예외, 기준일을 HTML 본문으로 제공한다. 임의 글자 수를 채우거나 이미지 내용을 확인하지 않고 게임 설명을 만들어 넣지 않는다.

### 3. 소유권 확인 방식 — 확인 필요, 장애로 확정 불가

표본 운영 페이지의 초기 HTML에는 AdSense 스크립트와 google-adsense-account 메타가 없었다. GoogleAdsVertical 사용은 주석 처리되어 있고 공통 레이아웃 광고는 KakaoAds다. 그러나 ads.txt가 정상이며 Google은 다른 연결 방법도 지원한다. 따라서 스크립트 부재만으로 거절 원인이라 할 수 없다. 관리 화면에서 선택한 확인 방식과 사이트 연결 완료 여부를 확인할 수 있을 때 대조한다.

### 4. noindex와 심사 정책 구분

이전의 검색 노출 정리는 운영에 반영되어 있다. 하지만 noindex는 검색 색인 지시이며 공개 페이지가 AdSense 심사 대상에서 자동 제외된다는 보장은 없다. 작업·투표·오류 화면 등은 Google 광고를 실제 도입할 때 별도의 광고 허용 정책으로 제어해야 한다. 현재 Kakao 광고를 Google 광고 위반으로 단정하지 않는다.

## 다음 순서

1. 홈 빈 통계와 잘못 해석될 수 있는 0 표시를 수정하고 배포 HTML을 검증.
2. 이미지 중심 4개 글을 실제 이미지 내용 기반으로 보강. 홈에 직접 연결된 타이탄 재련 우선.
3. 모바일에서 이미지 설명의 가독성, 메뉴, 광고 배치, 도구 실행을 확인.
4. 연결 상태 및 가능한 경우 Search Console의 대표 URL 렌더링·수집 결과 확인.
5. 변경 배포일과 재신청일을 기록한 뒤 재심사. 특정 글 수·글자 수·대기 일수로 승인을 보장하지 않음.

이번 작업은 분석 문서만 추가했으며 서비스 코드 수정, 배포, 재심사 요청은 하지 않았다.
