# 운영 화면 점검 및 홈 통계 수정 — 2026-09-21

요청 순서: 모바일·운영 화면 확인(4번) 후 홈 통계 수정(3번). 글 추가·공략 본문 수정·배포·재심사는 수행하지 않았다.

## 1. 운영 사이트 화면 점검

실제 운영 주소를 Chromium으로 열어 390px 모바일 에뮬레이션과 1440px 데스크톱에서 확인했다. 물리적인 스마트폰/Safari 테스트는 아니다. 대상은 한국어 홈, 공략 목록, 타이탄 재련 글, 전투 공식 통합 글, 체력 계산기다.

| 확인 대상 | 결과 |
|---|---|
| 5개 주소 × 2개 화면 크기 | 모두 HTTP 200, 관측한 페이지 JavaScript 예외 없음 |
| 이미지 | 확인 시점에서 깨진 이미지 0개 |
| 모바일 메뉴 | 메뉴 열기 → 공략 목록 이동 → 메뉴 자동 닫힘 정상 |
| 체력 계산기 | 체력 회복 속도를 111 → 121로 변경했을 때 계산 결과 갱신, 모바일·데스크톱 모두 확인. 기초 91·장식 8 조건에서 2분 12초 → 2분 7초, 단축 5.3초로 표시되어 페이지에 명시된 식과 일치 |
| 홈·목록·타이탄 재련 글 | 모바일 문서 가로 넘침 없음 |
| 전투 공식 통합 글 | 390px 화면에서 문서 폭 485px, 가로 넘침 발생 |
| 체력 계산기 | 390px 화면에서 문서 폭 448px, 설명 이미지가 오른쪽으로 넘침. 코드의 maxWidth: 400px가 부모보다 커질 수 있음 |
| 타이탄 재련 이미지 | 로딩은 정상이지만 모바일 기본 크기에서 작은 글씨를 읽기 어려움. 본문 설명 및 확대 접근 개선 후보 |
| 데스크톱 | 점검한 5개 페이지 모두 문서 가로 넘침 없음 |
| 광고 | 검사 환경에서 광고 슬롯에 소재가 채워지지 않음. 실제 광고가 표시된 상태의 겹침·조작 방해 여부는 미확인 |

광고 미표시를 광고 차단 또는 승인 거절 원인으로 확정하지 않는다. 전투 공식·계산기의 모바일 가로 넘침은 확인 사항으로 기록했으며, 이번에는 요청대로 홈 통계를 수정했다.

관측 증거는 작업 폴더의 `audit.local/live-results.json` 및 `audit.local/live-*.png`에 보존했다. 운영 사이트 데이터는 점검 중에도 갱신될 수 있으며, 이 결과는 AdSense 심사 당시의 화면을 재현한 것이 아니다.

## 2. 홈 통계 문제와 수정

### 원인

- `loadHomeStatistics()`는 시즌별 전체 조사 결과가 오기 전까지 player/power/realPower를 빈 객체로 반환한다. 기존 Top 100 표본과 전체 조사 표본을 섞지 않기 위한 처리다.
- 프리렌더 빌드에서는 전체 서버 집계를 생략한다. 그 상태에서도 플레이어 카드·활동 분포·전투력 카드가 렌더되어 `-` 또는 기본값 `0`이 나타났다.
- 방문 후 15초가 지나면 mounted=false가 되어, 나중에 집계가 성공해도 결과를 반영하지 못했다. 운영 모바일 첫 확인에서는 집계값이 표시되지 않았고, 이어진 데스크톱에서는 집계값이 표시되어 결과가 항상 비어 있는 것은 아니었다.

### 변경

- 플레이어 수·온라인 인원·활동·전투력·서버 활동 분포·플레이어 구성은 집계 성공 후에만 표시.
- 집계 중, 집계 지연, 프리렌더 미집계, 집계 실패를 한국어·영어·일본어 안내로 구분.
- 미집계/실패 시 조사 데이터로 이동할 링크 제공. 정상 수집된 서버 수, 카르츠 요약, 변화 기록은 유지.
- 15초 초과는 지연으로 표시하고, 늦게 도착한 정상 결과도 반영. 페이지를 떠난 경우에만 응답을 무시.
- 실제로 집계된 0은 유지. 서버 이동·닉네임 변경의 누락값도 임의의 0으로 바꾸지 않음.
- 전체 플레이어 집계를 위한 원자료 다운로드 구조 자체는 유지한다. 다운로드량·집계 시간 최적화나 서버 측 집계 스냅샷 생성은 이번 수정 범위가 아니다.

## 3. 검증

- 수정 Home 및 검증 스크립트 ESLint 통과.
- `scripts/verify-home-statistics.mjs`: 로컬 서버에 실제 서비스 모듈을 사용하고 작은 고정 API 응답을 제공해 상태 전환 검증.
- 세 언어의 프리렌더 미집계 안내와 수치 카드 제외 확인.
- 정상 집계에서 레벨 80 미만 플레이어 제외, 실제 온라인 0명 표시 확인.
- 응답을 17초 지연시켜 지연 안내 후 정상 수치로 복구되는 것을 확인.
- 플레이어 집계 실패 시 빈 카드 제외 및 나머지 통계 유지 확인.
- 기본 통계 실패 시 오류 안내 및 통계 카드 제외 확인.
- 검증 상태에서 390px 홈 가로 넘침 없음.

- `npm run build`: 첫 실행은 다른 경로 탐색 중 30초 시간 초과로 중단. 코드 변경 없이 한 번 재실행하여 전체 빌드 성공, sitemap 60개 생성.
- 생성된 ko/en/ja 초기 HTML: 미집계 안내, 서버 KPI 1개, 미집계 플레이어·전투력·활동 카드 제외 및 언어별 canonical 유지 확인.
- 배포용 파일을 로컬 preview로 실행해 동일한 7개 사례(세 언어 미집계 + 정상·지연·부분 실패·전체 실패)를 다시 검증, 모두 통과.
- `git diff --check` 통과.
- 운영 사이트에는 아직 배포하지 않았다. 따라서 운영의 기존 홈 및 모바일 가로 넘침은 이 작업만으로 변경되지 않는다.

검증 재실행: 로컬 개발 서버 실행 후 `node scripts/verify-home-statistics.mjs`. 배포용 preview는 `HOME_TEST_ORIGIN`을 해당 로컬 주소로 지정한다.
