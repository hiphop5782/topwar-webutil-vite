Top War 영원의 땅

영원의 땅 점령 점수 계산기

종료 시간과 서버별 현재 점수, 점령 시설을 설정하면 남은 시간 동안의 점수를 합산해 최종 예상 순위를 계산합니다. 입력 데이터는 브라우저에 저장되어 다음 방문에서도 이어서 사용할 수 있습니다.

계산 절차

다섯 단계로 예상 순위를 계산합니다

모든 단계는 항상 표시됩니다. 필요한 정보가 없을 때는 빈 상태와 안내 문구가 나타나므로 계산 구조를 미리 확인할 수 있습니다.

  1. 1종료 시간

    이벤트 종료 일자와 시각을 설정합니다.

  2. 2서버 등록

    비교할 서버 번호나 이름을 추가합니다.

  3. 3현재 점수

    각 서버의 현재 누적 점수를 입력합니다.

  4. 4점령 시설

    서버별 점령 시설을 지도에서 지정합니다.

  5. 5예상 순위

    분당 점수와 최종 예상 점수를 비교합니다.

1

전략 시간 범위 설정

점수 기준이 되는 시작 시간을 잠그고 종료 시간을 설정하세요.

시작 시간

시간을 설정한 뒤 잠그세요.

종료 시간

2

서버 등록

최종 점수와 순위를 비교할 서버를 추가합니다.

아직 등록된 서버가 없습니다. 비교할 서버를 먼저 추가하세요.

현재 0개 서버가 등록되어 있습니다.

3

시작 시간 기준 점수

잠근 시작 시간에 각 서버가 보유한 점수를 입력하세요.

서버를 등록하면 현재 점수 입력란이 표시됩니다.

4

서버별 점령 지역 설정 · 전체 지도

서버를 선택한 다음 지도 위 시설을 눌러 점령 상태를 배정하거나 해제합니다.

시설을 배정하려면 먼저 서버를 등록하세요.
총 0개 시설이 배정되었습니다.전체 서버 현황 모드
5

시간대별 예상 점수

슬라이더를 움직여 원하는 시각의 예상 점수와 순위를 확인하세요.

시작 시간을 잠그고 올바른 종료 시간을 설정하세요.

계산 방식

각 서버가 점령한 시설의 분당 점수를 합산한 뒤, 종료까지 남은 분을 곱해 현재 점수에 더합니다.

최종 예상 점수 = 현재 점수 + 시설 분당 점수 합계 × 종료까지 남은 분

결과 확인 시 주의사항

실제 결과는 시설 점령·상실 시각, 서버 간 전투, 이벤트 규칙 변경 등에 따라 달라질 수 있습니다.

이 도구는 현재 점령 상태가 종료 시점까지 유지된다고 가정한 참고용 예상치입니다.

자주 묻는 질문

단계별 화면을 숨기지 않아도 되나요?

모든 단계를 표시하고 입력할 수 없는 부분만 빈 상태나 비활성 상태로 안내하는 편이 사용자가 전체 계산 과정을 이해하기 쉽습니다.

최종 예상 점수는 어떻게 계산되나요?

현재 점수에 각 시설의 분당 점수와 종료까지 남은 분을 곱한 값을 더합니다.

입력한 정보는 어디에 저장되나요?

서버, 시설 배정, 종료 시간은 현재 브라우저의 로컬 저장소에 저장됩니다.
